# Exam Blueprint

## Source of truth

Start with the official certification page:

https://anthropic-partners.skilljar.com/claude-certified-associate-foundations-certification

Find and read the current official exam guide and preparation resources linked from the page before finalizing this document.

## Research requirements

Record:
- Guide title and version/date, if published.
- Official exam duration, number of questions, question types, and passing criteria if stated.
- Exact domain names, objective statements, and weights.
- Official sample-question availability and usage restrictions.
- Access date and source URLs.

## Coverage matrix

Create a traceability table with these columns:

| Domain | Official objective | Weight | Lesson IDs | Assessment IDs | Source |
|---|---|---:|---|---|---|

Populate this matrix only after verifying the current guide. Do not treat remembered or third-party syllabus summaries as authoritative when the official guide is accessible.

## Question distribution

Derive mock-exam question distribution from the verified official weights and format. Document rounding rules where domain percentages do not map cleanly to the exam length.

All practice questions must be original and clearly labeled as practice material.
